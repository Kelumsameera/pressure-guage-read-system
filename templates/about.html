About the Modbus Monitoring System

🧭 System Overview

This system reads data from Modbus TCP-enabled devices such as real-time readings, logs values to a MySQL database, and offers historical analysis with export functionality.

  • Real-time data monitoring with Flask-SocketIO
  • Data logging to MySQL
  • Interactive charts (Chart.js)
  • Date-filtered reports and Excel export
